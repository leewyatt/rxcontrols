RXImageView

Style class: rx-image-view

The RXImageView control extends Region and has all the properties of Region; it has no public substructure.

Css Property Values Default
-fx-clip-svg-path String (SVG path in 0-100 coordinate space) null

Clipping is supplied via -fx-clip-svg-path in CSS or setClipSvgPath(String) in Java. Predefined SVG path strings are exposed as constants on RXImageView (e.g. SHAPE_CIRCLE, SHAPE_HEXAGON, SHAPE_SHIELD). The image is cover-fit scaled to fill the control bounds; overflow is cropped. When the image is null, fails to load, or its metadata is not yet parsed, the control renders nothing.

RXTextField

Style class: rx-text-field

A base text-field control that adds left and right slots for user-supplied nodes. It does not bundle any built-in buttons or actions — set left / right with any Node (Label, Button, HBox, etc.).

Substructure

.rx-text-field — extends TextField
  .left-wrapper — StackPane (present only when left is set)
  .right-wrapper — StackPane (present only when right is set)

Pseudo-classes

CSS Pseudo-class Comments
showing-left-node applies when the left node is non-null
showing-right-node applies when the right node is non-null
showing-no-side-nodes applies when both left and right are null (mutually exclusive with the two above)

RXTextField does not expose any custom -rx-* CSS property. Use direct selectors on the substructure (e.g. .rx-text-field > .left-wrapper { -fx-padding: 0 4 0 0; }) for layout tuning.
